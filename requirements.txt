# LTX-2.5 Studio — runtime dependencies.
#
# Every direct dependency has a floor AND a ceiling. See docs/PLAN.md §5.1 for
# the reasoning; the short version is that the predecessor project shipped ~50
# unbounded requirements and got burned by a silent torch/torchaudio ABI break.
#
# Dev/test tooling (pytest, ruff) is NOT here — it lives in pyproject.toml's
# [project.optional-dependencies] dev extra, so the Space image stays lean.

# --- NOT PINNED, DELIBERATELY -------------------------------------------------
# `spaces` is intentionally absent. The Spaces platform pins its own version
# (live Spaces report 0.49.3 / 0.50.0 / 0.50.4 while PyPI is at 0.51.1), and a
# conflicting pin here breaks pip resolution at build time. The 2.3 repo's own
# AGENTS.md:19 states this rule and its requirements.txt:2 then violated it.
# The import is guarded in ltx25_studio/zerogpu.py so local dev works without it.
# ------------------------------------------------------------------------------

# --- torch trio: pinned exactly, and pinned TOGETHER --------------------------
# ZeroGPU supports exactly torch 2.8.0 / 2.9.1 / 2.10.0 / 2.11.0 (CUDA 12.8;
# sm_120 Blackwell needs cu128+). 2.11.0 is the ceiling.
# Trap: torchvision 0.28.0 hard-declares torch==2.13.0, so letting torchvision
# float silently drags torch past the ceiling. torchaudio must match torch
# exactly or the C++ ABI mismatch crashes the whole audio path on import.
#
# NOTE for whoever bumps these: tests/test_torch_trio_drift.py guards all three
# together — torch, torchaudio AND torchvision — so a mismatched bump fails the
# gate rather than the Space. Bump them as a set and let the test confirm it.
torch==2.11.0
torchvision==0.26.0
torchaudio==2.11.0

# --- diffusers: exact SHA, PEP 508 direct reference (not #egg=) ---------------
# LTX-2.5 is not in any release. 0.39.0 imports LTX2Pipeline fine and then fails
# LATE on a missing temporal_latent_upsampler — after ~70 GB of download. This
# SHA is HEAD at 2026-08-19T12:11:04Z and contains PR #14447 (LTX-2.5 merge,
# 2026-08-11) plus #14453 and #14462. ltx25_studio/preflight.py asserts
# diffusers.__version__ == "0.40.0.dev0" at startup so a wrong revision fails
# immediately instead of expensively. See PLAN §1.3.
diffusers @ git+https://github.com/huggingface/diffusers@ac56fa2f25c1c15b4cbaa1e0b3255e9bc38c06dc

# --- UI -----------------------------------------------------------------------
# gradio 5.x is END OF LIFE (last stable 5.50.0, 2025-11-21).
#
# PINNED EXACTLY, and it MUST EQUAL `sdk_version` in the Space README frontmatter.
# A range brackets 6.24.0 today and resolves to 6.30 tomorrow while sdk_version
# still says 6.24.0 — the Space would then serve one gradio and the environment
# would allow another. A drift test asserts the two agree. Upgrading is
# deliberately two edits: this line and sdk_version.
#
# Breaking changes from 5.x that affect us: gr.Video subtitle-tuple return
# removed; show_download_button / show_share_button -> buttons=[...]; gr.Audio
# show_controls -> show_recording_waveform; min_length / max_length ->
# event-listener validators.
gradio==6.24.0
