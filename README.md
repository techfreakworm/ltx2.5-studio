# LTX-2.5 Studio

A Gradio studio for [LTX-2.5](https://huggingface.co/Lightricks/LTX-2.5) — Lightricks' 22B
video + audio generation model — covering every mode the model supports, with
**user-uploadable LoRA** at inference time.

Runs locally on Apple Silicon (MPS) / NVIDIA (CUDA) and deploys to a private
Hugging Face Space on ZeroGPU.

Status: design locked, implementation starting. See [`docs/PLAN.md`](docs/PLAN.md).
